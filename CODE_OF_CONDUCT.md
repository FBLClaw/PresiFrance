# Code de conduite

Ce projet attend des contributions professionnelles, respectueuses et utiles.

Comportements attendus :

- rester courtois dans les issues, discussions et pull requests ;
- critiquer le code ou l'idee, pas la personne ;
- accueillir les questions de bonne foi ;
- signaler clairement les desaccords techniques avec des faits, exemples ou tests.

Comportements non acceptes :

- harcelement, insultes, attaques personnelles ou propos discriminatoires ;
- publication de donnees personnelles sans consentement ;
- spam, trolling ou perturbation volontaire du projet.

Les mainteneurs peuvent masquer, modifier ou supprimer des contributions qui ne respectent pas ce cadre.
